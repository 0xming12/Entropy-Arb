# NVDA 三日回放

- 在 Codex 云工作区运行单进程，进程优先级为 `nice -n 19`。实盘 EC2 只读取市场数据，优先用既有 SSM 私有转发，低优先级、逐文件下载。源路径仅为 logs/ 下的 NVDA 五档深度、Entropy BBO 和公开成交，不读取 .env。
- 一日定义为美东 09:30–16:00 的常规盘。11-26 休市，11-27 至 13:00 独立回放，不计入三个足时日。指定足时日为 11-25、11-30、12-01；缺这些日期时记录缺口，避免更换样本。确保文件覆盖开/收盘、检查双边有效盘口秒覆盖和最大连续缺口，去重 trades 的 (exchange_ts_ms, trade_id)，检查采集进程的中断日志。数据未齐继续等待。
- Entropy 买一卖一按 exchange_ts_ms/received_ts_ns 分别构造撮合与策略可见视图。五档深度用 ts-update_age_sec 回溯快照源时间。原始 BBO 有真实到达时间时优先使用；无同源帧的深度变化用可观测到达时间的上界并标明。Lighter 的时间使用采样记录与 update_age_sec，记录精度细节与缺口。不允许用未来记录推进策略决策。
- 吃单分 0、0.2、0.5 秒运行。仅读取生产 YAML 中与回放相关的字段到隔离副本。只在 Entropy 实际买一/卖一价格或数量变化的交易所时间加 300 ms 时判断信号，去掉 50/100 ms 定时网格。Entropy 进场盘口用这条模拟送达时间轴，撮合仍用交易所源时间。复用 f13c897 的 Engine._scan、_prepare_pair_order、_worst_case_check 和手续费、取整、量价、持仓限制。测试内存中修改持久闸门，不修改生产参数。Entropy 发单去程 550 ms，在交易所时间盘口中逐档截至限价撮合，处理零/部分成交；Entropy 有成交才在当时 Lighter 盘口走对冲并保留失败和单腿成本。有实测回程可说明如何用于后续发单时间，避免新数据提前可见。
- ALO 测试要区分 maker 手续费和原吃单费。做同方向信号后按 Entropy BBO 只挂单，进撮合时若变成可吃单则拒绝。成交带不能恢复订单 ID 与真实队列，给出明确的队首与已显示挂单在前两种假设，下单排队后才能计合格向对手方向成交，实际交易数量分摊盘口前方挂单；不允许光凭触价断定成交。明确撤单条件和延迟。单腿成交到 Lighter 盘口吃单对冲，平仓镜像，报告单腿及未闭合头寸。逆向选择以成交时 mid 与其后 1 秒内第一个不利 mid 或最低有符号变动统计，另外报可用观察数，不把缺失观察当未发生。
- 向 HL 公共 /info 取 io:NVDA fundingHistory，向 Lighter 公开 fundings 历史取 market 110 的每小时资金费率，复现实际结算时点、按有符号头寸与历史中间价计费。手续费用实盘已确认费率或明确按参考配置的估算。缺失费率和不完整的样本单独报告，禁止把未知资金费填零冒充净结果。
- 每组给出信号和成交、完成往返、平均净 bps（按单笔初始成交名义计算再平均）、美元净收益、资金费、开盘 30 分钟内/外（按开仓时间），并留每次尝试和往返明细。ALO 另列挂单成交率、1 秒逆向选择。停机或授权失效时记录阻塞并保留任务。
- 已有工具 `transfer.py` 提供短时 SSM 私有转发、CPU Credit 检查与单文件低负载复制，`../../tools/replay_depth.py` 提供无签名无下单的框架基类。旧分钟或旧一秒数据不能顶替新三日。下一次不要把旧脚本的示例静态中枢、费率或阈值作为生产实参。

## 运行命令

```sh
cd deployment/nvda_ops
python3 capture_inputs.py --include-early-close 2026-11-25 2026-11-27 2026-11-30 2026-12-01
python3 capture_inputs.py --download --include-early-close 2026-11-25 2026-11-27 2026-11-30 2026-12-01
nice -n 19 python3 replay.py --include-early-close --entropy-maker-bps VERIFIED_RATE --out ./output 2026-11-25 2026-11-30 2026-12-01
```

先验证指定三个足时交易日，提前收盘单列。ALO 当前实现用 2 秒挂单窗口，区分队首和盘口显示数量在前，采用 Lighter 本机已见盘口，并对额外等待或剩余单腿列出流动性影响。普通 IOC 固定行情晚到 300 ms，发单 550 ms，回执估计用已测 285 ms。ALO 继续使用原始实际收到时间。先核对当日可证实的实际费率后再运行。当前脚本每个交易日从独立起点比较，日末未平仓单列。若要跨日续持，先补齐盘外盘口与资金费并调整策略模拟。
